# MY SCHEDULE

Editorial Brutalism personal life planner.

## Requirements
- Node.js 20+
- npm

## Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Routes
- `/overview`
- `/calendar`
- `/todo`
- `/activity`
- `/habits`
- `/statistics`
- `/settings`

This is the Phase 1 foundation scaffold. Calendar interactions and persistent data are not implemented yet.
